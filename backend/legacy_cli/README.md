# CLI Legado // VT Doc Guardian (v3.3)

Este diretório contém o script original em linha de comando (`vt-doc-guardian.py`) desenvolvido para varredura recursiva de diretórios locais utilizando a API do VirusTotal.

## Uso standalone

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install python-magic python-dotenv requests
python3 vt-doc-guardian.py
```
